## Wdrożone 22.11.2026 (do zbiorczego wpisu; ogłoszenie o angielskiej wersji wysłane na #announcements 23.11)

- Komendy mają angielskie nazwy na wszystkich serwerach: `/wisielec` → `/hangman`, `/wisielec-top` → `/hangman-top`, `/pogoda` → `/weather`, `/ciekawostka` → `/fact`, `/dowcip` → `/joke`, `/kamien-papier-nozyce` → `/rock-paper-scissors`, `/kalendarz-adwentowy` → `/advent-calendar`. Opcje komend też po angielsku (np. `/weather now city:`). Opisy komend są po polsku dla osób z Discordem po polsku. / Commands now have English names in every server (list above); options are in English too. Command descriptions follow your Discord language.
- Nowa opcja w panelu: język bota na serwerze (Ustawienia → Język: Polski/English). Po angielsku są już m.in. komunikaty o uprawnieniach, cooldownie i wyłączonych komendach oraz `/help`; reszta modułów jest w trakcie tłumaczenia. / New dashboard setting: the bot language per server (Settings → Language). Permission, cooldown and disabled-command messages and `/help` are already in English; other modules are being translated.
- Na serwerach z językiem angielskim gry ze słowami po polsku (`/wordle`, `/hangman`, `/fact`, `/8ball` i rankingi) są na razie niedostępne. / On English servers the Polish word games are unavailable for now.
- Wyłączenia komend ustawione w panelu przeniesione automatycznie na nowe nazwy. / Disabled commands in the dashboard were moved to the new names automatically.
- `/say` ma opcjonalny obrazek (PNG, JPG, GIF, WEBP do 8 MB), w trybie embed wyświetlany w środku embeda. / `/say` has an optional image (PNG, JPG, GIF, WEBP up to 8 MB), shown inside the embed in embed mode.
